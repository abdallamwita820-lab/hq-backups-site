HQ Backups

Automatic, verified backups from a private local HQ database to the owner’s Google Drive.

After Google sign-in and approval of the first real upload, the app takes a dated SQLite snapshot each day while the Mac is awake, signed in, and online. It downloads the uploaded file again and verifies its checksum and database integrity.

Google Drive access

HQ Backups uses Google OAuth with the drive.file scope to create and manage its backup files in a private folder named HQ Backups. It uses this access to upload, verify, and retire dated backups.

Files are sent over HTTPS as ordinary SQLite snapshots. HQ Backups applies no additional file encryption before upload.
