Privacy Policy

How the HQ Backups desktop app handles local data and Google Drive access.

Google Drive access

HQ Backups is a personal macOS app. The owner signs in with Google and grants the https://www.googleapis.com/auth/drive.file OAuth scope. This per-file permission lets the app create, list, upload, download, and move to Trash files it creates or is authorized to access. HQ Backups uses it for the private HQ Backups folder and its backup files. It does not request full access to Google Drive.

OAuth credentials

Google handles sign-in. The app uses rclone on the Mac to obtain and refresh access tokens. The OAuth client settings and tokens are stored in a local configuration file inside the private HQ data directory, with file permissions restricted to the macOS account. They are excluded from backup snapshots, this website, and public files. HQ Backups does not receive the Google account password.

What is uploaded and why

After the owner approves uploads, HQ Backups creates verified, dated copies of the selected local HQ SQLite database and sends them over HTTPS to the owner’s Google Drive. It downloads each uploaded file for checksum and integrity verification. It does not upload the live database file or send records to the website.

Snapshots are ordinary SQLite files uploaded without additional application-level encryption. Anyone who obtains a copy of a snapshot can read its contents. HQ Backups checks the destination’s sharing settings and does not make the folder or its files public.

Use and sharing of Google user data

HQ Backups uses Google user data only to authorize and operate the backup and recovery workflow. Google processes transfers and stores the files in the owner’s Drive. HQ Backups has no separate server that receives backups or Google OAuth credentials. It does not sell the data, use it for advertising, or share it with other recipients.

HQ Backups’ use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

After a successful verified upload, the app moves its own versions older than 90 days to Google Drive Trash while keeping a verified recovery copy. The owner can pause future uploads in HQ, delete files in Drive, and revoke the app’s access in Google Account connections. Revoking access leaves previously uploaded files in Drive.

This website

These pages are informational. They do not offer sign-in, accept files, or use application analytics. GitHub Pages hosts the site and may log visitor IP addresses for security. GitHub’s privacy statement describes its practices.
